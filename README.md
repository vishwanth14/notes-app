## Technology Stack

- MongoDB
- Express.js
- React
- Node.js
- Mongoose
- Axios
- Vite

## Database

MongoDB connection:

mongodb://localhost:27017/notes_db

## Backend Setup

Open a terminal in the server directory:

cd server
npm install
npm start

Backend:

http://localhost:5000

## Frontend Setup

Open another terminal in the client directory:

cd client
npm install
npm run dev

Frontend:

http://localhost:5173

## REST API

POST /api/notes
GET /api/notes
DELETE /api/notes/:id

## Features

- Create notes
- View notes
- Delete notes
- MongoDB persistence
- Loading state
- Empty state
- Localized date formatting
- React state synchronization
- Axios REST API communication
- CORS support
